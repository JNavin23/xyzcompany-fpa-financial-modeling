# XYZCompany – FP&A & Financial Modeling

## Overview

An MNC-style FP&A and financial modeling project built in Excel to simulate the responsibilities of a Financial Planning & Analysis / Financial Analyst team.

The project covers historical analysis, budgeting, forecasting, variance analysis, management reporting, 3-statement modeling, scenario analysis, and DCF valuation.

## Key Areas Covered

- Historical financial analysis
- Data validation and profiling
- Budget assumptions
- Revenue forecasting
- Operating expense forecasting
- FY2027 Budget vs Actual analysis
- Variance and driver analysis
- FP&A management dashboard
- P&L forecasting
- Cash Flow modeling
- Balance Sheet modeling
- 3-Statement financial model
- Base, Upside and Downside scenarios
- DCF valuation
- DCF sensitivity analysis

## Purpose

This project demonstrates how financial data can be transformed into management-ready insights through budgeting, forecasting, variance analysis, financial modeling, scenario planning, and valuation.
